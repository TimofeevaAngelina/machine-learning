# Machine Learning: CycleSense (Master's Thesis Project) 🧬📱

Данный репозиторий содержит код, данные и результаты магистерского исследования (СПбГЭТУ «ЛЭТИ»), посвященного разработке и обучению моделей машинного обучения для мобильного приложения **CycleSense**. 

Приложение предназначено для мониторинга женского здоровья и краткосрочного прогнозирования психофизиологического состояния (уровень энергии, стресса, настроения, боли) на основе объективных данных с носимых устройств (ЧСС, ВСР, сон, шаги) и фаз менструального цикла.

## 🎯 Задачи проекта
1. Провести обзор научной литературы о физиологических изменениях (ВСР, ЧСС) во время менструального цикла.
2. Сгенерировать реалистичный синтетический датасет (из-за конфиденциальности реальных медицинских данных), заложив в него реальные биологические зависимости.
3. Разработать и обучить модель прогнозирования временных рядов (GRU) для предсказания субъективных показателей на 3 дня вперед.
4. Подготовить модель к интеграции в Android-приложение (конвертация в TensorFlow Lite).

## 🛠 Стек технологий
* **Язык:** Python
* **Анализ данных:** Pandas, NumPy
* **Визуализация:** Matplotlib, Seaborn
* **ML и DL:** Scikit-learn, TensorFlow / Keras
* **Модель:** GRU (Gated Recurrent Unit) для работы с временными рядами.

## 🔬 Ключевые особенности (Feature Engineering & Data Generation)
Особое внимание в проекте уделено реалистичности данных:
* **Умная генерация циклов:** На основе датасета `FedCycleData` сгенерировано более 44 000 записей (дней циклов), разбитых на 4 фазы (менструальная, фолликулярная, овуляторная, лютеинизма).
* **Расчет BMR и калорий:** Использована формула Миффлина-Сан Жеора для расчета базового метаболизма, основанная на реальных антропометрических данных (вес, рост, возраст).
* **Моделирование ЧСС и ВСР (HRV):** Пульс в покое сгенерирован с помощью линейной регрессии (зависимость от возраста) на основе реального датасета *Whoop Fitness*. ВСР (RMSSD) смоделирована через логнормальное распределение.
* **Логические взаимосвязи:** Заложены биологические паттерны. Например, уровень стресса напрямую зависит от ВСР (чем ниже ВСР, тем выше стресс), пульса и качества сна. Уровень энергии и концентрации зависит от стресса и сна.
* **Симуляция «грязных» данных:** В датасет намеренно добавлено 5% пропущенных значений и 1% выбросов (аномалий пульса), чтобы модель училась работать с реальными, неидеальными данными.

## 📈 Метрики качества (ML)
